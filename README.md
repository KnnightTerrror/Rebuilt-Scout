# REBUILT Scout

Scouting app for the FRC 2026 game **REBUILT**: match and pit scouting, automatic team rankings,
scout assignments, pre-match briefs, team comparison, data checks, QR transfer and a shared picklist.

**Open the app:** https://knnightterrror.github.io/Rebuilt-Scout/

Setup steps (live team sync with Firebase, event setup, installing on phones) are in [SETUP.md](SETUP.md).
